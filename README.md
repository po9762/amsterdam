# Weekend Amsterdam

Programma, wandelroutes en GPX-bestanden voor ons weekend in Amsterdam.

## Inhoud

- `index.html`: de pagina met programma, kaart en downloads
- `gpx/`: de wandelingen als GPX-bestand, apart en gebundeld

## Online zetten met GitHub Pages

1. Maak op GitHub een nieuwe repository aan, bijvoorbeeld `amsterdam-weekend`.
2. Upload de inhoud van deze map (de `index.html`, deze README en de map `gpx`) via **Add file → Upload files**.
3. Ga naar **Settings → Pages**.
4. Kies bij **Source** voor **Deploy from a branch**, branch `main`, map `/ (root)`, en klik **Save**.
5. Na een minuut of twee staat de pagina op `https://<jouw-gebruikersnaam>.github.io/amsterdam-weekend/`.

Let op: een GitHub Pages-site is openbaar voor iedereen die de link kent.
